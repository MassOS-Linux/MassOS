massos-logo.png is the main MassOS logo, used for nearly all purposes.

massos-logo-small.png is a smaller version of the main MassOS logo, whereby
exact image dimensions matter.

massos-logo-extrasmall.png is an even smaller version of the main MassOS logo,
whereby again, exact image dimensions matter.

maossos-logo-notext.png is a variant containing only the MassOS graphic,
without the MassOS text underneath. Useful as an icon, etc.

massos-logo-sidetext.png is primarily designed for use in the Plymouth boot
splash screen, whereby the OS logo for the BGRT theme is expected to display
at the bottom of the screen, underneath the spinner.

massos-logo-bios.jpg is a special version of the MassOS logo designed to be
used with the AMI ChangeLogo utility, for changing the logo of your computer's
BIOS firmware. Because there is objectively no better image than the MassOS
logo.
